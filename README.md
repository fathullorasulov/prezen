# Российская Федерация: 1991–2026 — Интерактивная Prezi-Презентация

Интерактивный веб-сайт в формате пространственной презентации (Zoomable UI в стиле Prezi), охватывающий историю Российской Федерации с 1991 по 2026 год (12 основных станций + 6 вложенных круговых субузлов профиля страны).

## Быстрая публикация и получение ссылки на GitHub Pages

В проект уже встроен автоматический пайплайн `.github/workflows/deploy.yml` и настроен относительный путь сборки (`base: './'` в `vite.config.ts`), поэтому сайт работает по любой ссылке без дополнительной настройки путей.

### Шаг 1. Загрузите код в ваш репозиторий GitHub
```bash
git init
git add .
git commit -m "Initial commit: Russia 1991-2026 interactive presentation"
git branch -M main
git remote add origin https://github.com/<ВАШ_ЛОГИН>/<ИМЯ_РЕПОЗИТОРИЯ>.git
git push -u origin main
```

### Шаг 2. Включите GitHub Pages (один раз)
1. Откройте ваш репозиторий на **GitHub**.
2. Перейдите во вкладку **Settings** → в левом меню выберите **Pages**.
3. В разделе **Build and deployment** → **Source** выберите **GitHub Actions**.
4. Через 30–60 секунд после пуша во вкладке **Actions** завершится сборка, и ваша готовая ссылка появится по адресу:
   `https://<ВАШ_ЛОГИН>.github.io/<ИМЯ_РЕПОЗИТОРИЯ>/`

## Локальный запуск

npm install
